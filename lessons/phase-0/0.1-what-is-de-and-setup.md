## ส่วนที่ 1: Data Engineer ทำอะไรจริง ๆ?

ลองนึกถึงร้านกาแฟเครือใหญ่ 500 สาขา:
- ทุกสาขามีเครื่อง POS บันทึกการขายลง **ฐานข้อมูลของแอป** (เรียกว่า OLTP)
- ฝ่ายการตลาดอยากรู้ "เมนูไหนขายดีที่สุดในแต่ละภาค ช่วงหน้าฝน?"
- Data Scientist อยากทำโมเดลพยากรณ์ยอดขาย

ปัญหาคือ ข้อมูลกระจัดกระจาย, ฟอร์แมตไม่ตรงกัน, และถ้าไป query ฐานข้อมูลของแอปตรง ๆ แอปจะช้าจนลูกค้าจ่ายเงินไม่ได้!

**Data Engineer คือคนแก้ปัญหานี้** โดยสร้างระบบที่:

| ขั้นตอน | ทำอะไร | ตัวอย่างเครื่องมือ |
|---|---|---|
| **Extract** | ดึงข้อมูลจากต้นทาง | Python, API, CDC |
| **Load** | เก็บลงที่เก็บกลาง | Data Lake (S3/GCS), Warehouse (BigQuery/Snowflake) |
| **Transform** | ทำความสะอาด รวม คำนวณ | SQL, dbt, Spark |
| **Orchestrate** | ตั้งเวลาให้รันเอง ต่อกันเป็นลำดับ | Airflow |
| **Monitor** | เช็กว่าข้อมูลถูก ครบ ทันเวลา | Data tests, alerts |

### DE vs ตำแหน่งใกล้เคียง

| ตำแหน่ง | คำถามหลักที่ตอบ |
|---|---|
| **Data Engineer** | "ข้อมูลมาถึงถูกต้อง ครบ ทันเวลาไหม?" |
| Data Analyst | "เกิดอะไรขึ้นในธุรกิจ?" (Dashboard, รายงาน) |
| Data Scientist | "จะเกิดอะไรขึ้น?" (โมเดล, สถิติ) |
| Analytics Engineer | อยู่ระหว่าง DE กับ DA — เน้น SQL/dbt จัดโมเดลข้อมูล |

> 🧠 **Mindset สำคัญที่สุดของ DE:** ข้อมูลผิดแบบเงียบ ๆ อันตรายกว่า pipeline ที่พังแบบมีเสียง
> เพราะคนจะเอาตัวเลขผิดไปตัดสินใจโดยไม่รู้ตัว

### 2.3 ตั้งค่า Git ครั้งแรก
เปิด Terminal (ใน VS Code กด `` Ctrl+` ``) แล้วพิมพ์:

```bash

git config --global user.email "อีเมลที่ใช้สมัคร GitHub"
git config --global init.defaultBranch main
```

## ส่วนที่ 3: Git เบื้องต้น — "Save game ของโปรแกรมเมอร์"

Git ช่วยเก็บประวัติทุกการเปลี่ยนแปลงของโค้ด ย้อนกลับได้ ทำงานเป็นทีมได้

```
 Working Directory  ──git add──▶  Staging Area  ──git commit──▶  Local Repo  ──git push──▶  GitHub
   (ไฟล์ที่แก้อยู่)                  (เตรียมบันทึก)                 (ประวัติในเครื่อง)              (ออนไลน์)
```

คำสั่งที่ใช้ 90% ของเวลา:

| คำสั่ง | ความหมาย |
|---|---|
| `git init` | เริ่มใช้ Git ในโฟลเดอร์นี้ |
| `git status` | ดูว่าไฟล์ไหนเปลี่ยน (**พิมพ์บ่อย ๆ!**) |
| `git add <ไฟล์>` / `git add .` | เลือกไฟล์ที่จะบันทึก |
| `git commit -m "ข้อความ"` | บันทึก 1 จุด |
| `git log --oneline` | ดูประวัติ |
| `git push` | ส่งขึ้น GitHub |

### ลองทำ (พิมพ์เองนะ!)

```bash
cd D:\road-to-data-engineer
git init
git status
git add README.md PROGRESS.md lessons
git commit -m "Start my data engineering journey"
git log --oneline
```

จากนั้นสร้าง repo ใหม่บน GitHub ชื่อ `road-to-data-engineer` (ไม่ต้องติ๊ก README) แล้ว:

```bash
git remote add origin https://github.com/<username>/road-to-data-engineer.git
git push -u origin main
```
